# TrustChain Frontend

Modern, blockchain-secure certificate verification portal.

## Setup Instructions
1.  Navigate to the `frontend/` directory.
2.  Install dependencies: `npm install`
3.  Start the development server: `npm run dev`
4.  Access the app at `http://localhost:5173` (or the port Vite provides).

## Features
- **Public Verifier**: Upload PDF/Image or search by hash.
- **Issuer Dashboard**: Authorized institutions can anchor new credentials.
- **Admin Panel**: Manage issuer authorizations.
- **Responsive Design**: Mobile-friendly Tailwind layout with glassmorphism.
- **Multi-Factor Trust Engine**: Live blockchain query + AI forensics simulation.
